# AI 类视频分类与命名

所有专业 AI 视频先归入一级分类 `AI类视频`，再按观众看完后要解决的主要问题选择一个二级分类。不要让一条视频同时拥有两个主分类。

| `format_type` | `category_code` | 二级分类 | 主要判断 | 三级分类示例 |
| --- | --- | --- | --- | --- |
| `tool_explainer` | `ai_tool_explainer` | `AI工具实操讲解类` | 讲清任务、输入、执行、结果 | Codex、Skill、Agent、插件、自动化工具 |
| `news_explainer` | `ai_news_explainer` | `AI新闻与产品更新解读类` | 讲清事件、日期、变化、影响 | 模型发布、产品更新、公司动态、政策事件 |
| `list_video` | `ai_list_video` | `AI榜单、推荐与对比类` | 讲清选择范围、比较维度或排序依据 | 工具推荐、能力对比、TOP 清单、有依据榜单 |

## 路由规则

1. 先判断视频给观众的主要承诺，而不是只看标题中的关键词。
2. 核心是“怎么使用并看到结果”时选工具实操类。
3. 核心是“最近发生了什么以及为什么重要”时选新闻解读类。
4. 核心是“多个选项怎么选或为什么这样排”时选榜单对比类。
5. 混合题材只保留一个主分类，其余内容作为辅助信息。例如“新模型发布后怎么使用”如果主要展示操作结果，归工具实操类；如果主要解释发布变化，归新闻解读类。
6. 无法判断主要承诺且不同分类会显著改变成片结构时，先向用户确认。

## 项目命名

项目展示名使用：

```text
<二级分类短名>-<主题短名><两位序号>
```

二级分类短名固定为：

- `AI工具实操讲解`
- `AI新闻解读`
- `AI榜单对比`

示例：

- `AI工具实操讲解-自由导演样片01`
- `AI新闻解读-模型产品更新01`
- `AI榜单对比-AI编程工具01`

主题短名必须能区分具体选题，结尾必须使用两位数字。文件夹可以继续使用英文 slug，但 `source_brief.json.project_name` 必须保留规范中文展示名。

## 结构化记录

在 `source_brief.json` 写入：

```json
{
  "project_name": "AI工具实操讲解-自由导演样片01",
  "classification": {
    "level_1": "AI类视频",
    "level_2": "AI工具实操讲解类",
    "level_3": "Codex / Skill / Agent",
    "category_code": "ai_tool_explainer"
  }
}
```

`level_3` 根据具体题材填写，不建立封闭枚举；其他三个分类字段必须与 `format_type` 一致。
