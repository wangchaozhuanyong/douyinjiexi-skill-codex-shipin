# 蚂蚁AI 热榜银河模板设计合同

适用范围：`scheme_7_ai_hot_rank_top5` 的 `ant_ai_hotlist_extended` 变体。

这个合同只规定固定视觉模板和渲染验收。真实 AI 热榜扫描、排序、文案、合规、配音、Qingdou 和发布链仍由方案7主流程负责。

## 固定目标

- 画幅：`1080x1920`，9:16。
- 品牌：`蚂蚁AI`。
- 固定 CTA：`关注 蚂蚁AI`。
- 背景：真实宇宙星云质感，深蓝黑、紫蓝、洋红和少量暖光。
- 前景：透明玻璃榜单卡片，背景必须可见。
- 动效：银河内部慢速旋转，底图不得整体缩放、漂移或推拉。
- 预览：先在线预览，再导出 MP4 / WebM / 封面图。

## 背景层合同

背景必须拆成 4 层：

1. 固定宇宙底板
   - 使用真实星云纹理或高质量程序化星云。
   - 底板本身保持稳定，不允许 `scale`、Ken Burns、整图推近、整图左右漂移。
   - 中心阅读区可以局部压暗，但不能变成黑板。

2. 银河内部旋转层
   - 银河盘是独立图层，不是整张背景。
   - 银河中心偏右、偏上，带椭圆透视和羽化边缘。
   - 旋臂/纹理在盘面内部慢速旋转。
   - 边缘必须羽化，不能像贴纸。

固定参数：

```json
{
  "centerX": 0.52,
  "centerY": 0.44,
  "width": 1.18,
  "tiltDeg": -17,
  "scaleY": 0.62,
  "rotationDuration": 42,
  "opacity": 0.58,
  "blendMode": "screen",
  "maskFeather": 0.72
}
```

3. 高级质感层
   - 必须包含暗角、细颗粒、冷暖光分层、中心柔光、星尘微闪。
   - 流星只允许少量、低频、短促，不允许网页粒子感。
   - 高级感来自更暗、更稳、更有层次，而不是更亮或更多特效。

4. 景深层
   - 前景细尘略虚，银河主体清楚，远处星云更柔。
   - 文字阅读区用局部阴影和轻模糊服务可读性。

## 玻璃卡片合同

卡片是透明玻璃面板，不是黑色遮罩。

固定参数：

```json
{
  "x": 0.075,
  "y": 0.31,
  "width": 0.85,
  "height": 0.39,
  "radius": 36,
  "backgroundAlpha": 0.26,
  "minBackgroundAlpha": 0.24,
  "maxBackgroundAlpha": 0.34,
  "blur": 5,
  "borderAlpha": 0.18,
  "innerGlowAlpha": 0.08
}
```

要求：

- 背景必须能透过卡片看到。
- 大面积背景填充 alpha 不得超过 `0.34`。
- 字体可读性通过局部文字阴影、局部 feather dim、细边框和轻 blur 解决。
- 禁止整块 `rgba(0,0,0,0.7)`、白板、厚实磨砂黑底、全屏遮罩。

## 文案层合同

文案不是固定台词，而是固定语法。

标题结构：

```text
第N集 | M.D AI热榜TOP5 | {{五条内容背后的共同趋势}}
```

Rank 结构：

```text
第{{rank}}条，{{具体AI产品/模型/功能/事件}}。
来源是{{source_title}}，时间是{{visible_date}}。
它现在值得看，是因为{{why_now}}。
对普通用户来说，最直接的动作是{{viewer_action}}。
```

结尾必须保留品牌 CTA：

```text
关注 蚂蚁AI
```

## 预览合同

固定预览模板：`templates/ant_ai_hotlist_galaxy/preview.html`。

预览必须支持：

- 播放 / 暂停。
- 显示 / 隐藏玻璃卡片。
- 卡片透明度调节，范围 `0.24-0.34`。
- 银河速度调节。
- 质感强度调节。
- 导出当前封面帧。
- 录制 6 秒预览 WebM。

## 禁止项

- 整张图放大缩小。
- Ken Burns 推拉。
- 整张图左右漂移。
- 黑色实心卡片。
- 低质粒子 demo。
- 背景完全被卡片盖住。
- 无真实来源的 AI 热榜内容。
- 把参考视频作者、文案、字幕、画面、身份或水印复制进新视频。
