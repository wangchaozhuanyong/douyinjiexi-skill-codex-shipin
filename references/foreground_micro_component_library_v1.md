## 1. 微组件总规则

### 1.1 激活数量与视觉预算

- 9:16 推荐 2–4 个组件类型；16:9 推荐 2–5 个；硬上限 5 个。
- 同屏可见实例硬上限 9 个；C18、C21、C26 等重复件按实例计数。
- 同时可见的文字型微组件不超过 3 个。
- 同一锚点区域最多 2 个组件；同一语义功能不得重复。
- 竖版视觉权重总和不超过 7；横版不超过 9。
- `motion_weight >= 3` 或 `dominant=true` 的组件同时只能出现一个。
- 微组件动画并发上限为 2；母模块处于核心 `process` 动作时，只允许叠加一个轻量状态件。

### 1.2 组合优先级

```text
1 个信息载荷件：参数 / 文件 / 证据 / 数值
+ 1 个过程或状态件：进度 / 校验 / 分支 / 置信
+ 0–1 个边界或风险件
+ 0–1 个最终确认或结论件
```

组件不能为了“丰富画面”而出现。没有对应信息时，不创建 DOM。

### 1.3 文字硬限制

- 9:16 微型文字不小于 22px；16:9 不小于 20px。
- 超限顺序：改写为名词短语 → 删除重复主语 → 把说明移回母模块 → 仍超限则不使用该组件或拆镜头。
- 禁止缩字、压字宽、横向滚动、两行以上状态文案。

### 1.4 动画接入

```js
// 组件不创建独立无限时间线，只接入母模块主时间线
parentTl.add(componentTl, "process+=0.12");
```

- 母时间线标签：`assemble / load / process / resolve / hold / exit`。
- 组件内部标签：`dock / reveal / state / resolve / stow`。
- 状态必须遵循：`hidden → docked → active → resolved → stowed`。
- 禁止 `hidden → resolved`，禁止普通淡入、普通左右滑入和无意义循环。

### 1.5 全局 QA 硬失败

1. 微组件脱离 M01–M20 独立成页或成为主画面。
2. 组件第一眼像普通 tag、badge、按钮、圆点、图标或网页控件。
3. 组件没有承载任何真实文案、状态、数值、来源、条件或操作信息。
4. 组件从屏幕外普通滑入，未从母模块接口、槽位、刻度或结构中出现。
5. 同屏组件类型超过 5 个，或可见实例超过 9 个。
6. 同时出现两个以上无因果关系的主要微组件运动中心。
7. 组件文字小于最小字号、贴边、溢出、压缩或遮挡母模块正文。
8. 组件重复母模块已经表达的信息，没有新增语义功能。
9. 光效扫过文字，或组件持续呼吸、旋转、抖动。
10. 使用 Three.js、WebGL、真实 3D 模型或离线 3D 渲染才能成立。

## 4. C01–C30 微组件详细规范

# C01｜参数芯片｜Parameter Chip

**类别：** 输入与条件
**集成模式：** `additive`
**作用：** 承载一个输入参数、关键词值、模型设置或限制值，并明确它已经被装入母模块。

## 适合嵌入的大模块

- **优先：** M01 数据铸造槽、M11 参数影响风洞、M15 决策配重引擎
- **允许：** M01 数据铸造槽、M06 操作路径芯轨、M11 参数影响风洞、M12 模型架构解剖台、M15 决策配重引擎、M19 反馈迭代轨道
- **锚点：** `input_port`, `metric_mount`, `node_mount`
- **母时间线阶段：** `load`, `process`

## 承载的信息类型

参数名、参数值、模型设置、输入关键词、限制值。

## 自动选择标签

- **正向标签：** 输入参数、模型设置、变量、权重、选项
- **触发词：** 参数、温度、步数、上下文、权重、值为
- **排除：** 完整句子、来源证据、最终结论

## 静态视觉描述

一枚短矩形钛金属芯片，四角不是圆角，而是带 2–4px 切角；左侧有 3–5 枚微型接触针，右侧是低反射文字面，背面可见一条陶瓷绝缘层。芯片必须插在母模块的真实槽口或刻度位内，露出高度约 6px，不能漂浮。

- **材质：** 深钛金属、黑色陶瓷绝缘层、冷青接触光、哑光文字面
- **相对尺寸：** 宽度为父锚点 10%–22%，高度为 5%–10%。
- **9:16：** 同一行最多 3 枚；两行堆叠时每行最多 2 枚。
- **16:9：** 可横排 2–4 枚，但总宽度不超过锚点 72%。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【参数名】` | 6 | 1 | 是 | — |
| `【参数值】` | 8 | 1 | 是 | — |

## 动态出现方式

接触针先从槽内伸出 2px，芯片再由母模块内部向外抬升 6px；边缘光必须从接触针传到文字面。

## 动态过程中每一步怎么变化

1. 接触针按从上到下顺序接通。
2. 芯片抬升并在导向槽末端停止，不回弹。
3. 文字以浅凹刻遮罩从左到右显影。
4. 锁定后只保留一条稳定边缘光。

### 状态变化

- `dormant`：芯片藏在槽内，只见切角边。
- `loaded`：露出 6px，参数值清晰。
- `active`：一侧接触针保持亮，表示正在参与计算。
- `locked`：末端机械止动片闭合。
- `invalid`：止动片保持打开，并出现一条琥珀色绝缘缝。

**退出：** 先收文字遮罩，再让止动片打开，芯片沿原槽回收；不得向屏幕外飞走。

## 音效建议

- 接触针：极轻电子 tick。
- 止动片：短促金属 click，低于人声 16–18dB。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-parameter-chip` 内含 `.mc-pins`、`.mc-body`、`.mc-name`、`.mc-value`、`.mc-stop`。
- **CSS：** 使用 `clip-path: polygon(...)` 做切角；双伪元素模拟厚度与陶瓷层；文字面独立哑光层。
- **SVG：** 仅在需要针脚微刻度时使用内联 SVG，不依赖图标。
- **GSAP：** `dock` 拉伸针脚，`reveal` 将芯片 `translateY(-6px)`，`state` 切换止动片和边缘光。
- **伪 3D：** 继承母模块 perspective；芯片只允许 `translateZ(4–10px)`，不独立旋转。
- **素材：** 无需图片素材。
- **低动态模式：** 针脚直接切换接通状态，芯片在 180ms 内分两段抬升。

## 组合预算

- `visual_weight=1`，`motion_weight=1`，`text_weight=1`，`dominant=false`。
- 单个母模块最多 4 个实例；每增加一个实例，视觉权重增加 0.45。
- **适合搭配：** C03, C24, C27, C29
- **避免同用：** C05
- **可接转场：** TR04, TR05

## 禁止事项

- 不要做成普通圆角 tag。
- 不要悬浮、随机漂移或上下呼吸。
- 不要把多个参数塞进一枚芯片。
- 不要用彩色渐变区分参数。

## QA 失败判定

- 没有插入母模块槽口，像浮动标签，失败。
- 接触针和芯片同时无因果弹出，失败。
- 文字超限后缩小字号，失败。
- 四枚以上芯片挤压主信息区，失败。

# C02｜条件夹片｜Constraint Clamp

**类别：** 输入与条件
**集成模式：** `slot_enhancer`
**作用：** 把必要条件、范围、例外或前置要求实体化，并夹住它所约束的文字或路径。

## 适合嵌入的大模块

- **优先：** M04 错误校准仪、M14 风险守门闸、M18 误区分离器
- **允许：** M01 数据铸造槽、M04 错误校准仪、M06 操作路径芯轨、M11 参数影响风洞、M14 风险守门闸、M18 误区分离器
- **锚点：** `boundary_mount`, `input_port`, `node_mount`, `risk_mount`
- **母时间线阶段：** `load`, `process`, `resolve`

## 承载的信息类型

必要条件、适用范围、前提、例外、负面限制。

## 自动选择标签

- **正向标签：** 限制条件、前提、边界、必须满足、仅当
- **触发词：** 前提、条件、仅限、必须、不要、除非、范围
- **排除：** 无条件结论、纯数值指标、来源日期

## 静态视觉描述

一对从母模块边缘伸出的 U 形精密夹爪，中间夹着一枚窄型条件片。夹爪内侧有真实齿槽和压力刻度，条件片为深灰陶瓷金属，文字位于不反光区域。夹片必须围住被约束对象的边缘或连接口，不能单独放在空白处。

- **材质：** 枪灰合金夹爪、陶瓷金属条件片、低饱和琥珀状态线、黑色压力刻度
- **相对尺寸：** 宽度为父锚点 14%–32%，高度为 6%–12%。
- **9:16：** 优先放在被约束文字下沿或侧沿；不得横跨两列。
- **16:9：** 可夹住一段路径或结果板边缘，最大宽度不超过父锚点 38%。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【条件名】` | 8 | 1 | 是 | — |
| `【条件值】` | 12 | 1 | 否 | — |

## 动态出现方式

左右夹爪从母模块自身的机械缝中伸出，先定位边界，再夹合条件片；不从画面外左右滑入。

## 动态过程中每一步怎么变化

1. 夹爪沿刻度伸出并停在实际边界。
2. 条件片从夹爪内部翻至正面。
3. 压力齿逐格扣合，文字随齿槽遮罩显影。
4. 条件满足后，止动销完全落入；不满足时停在半齿。

### 状态变化

- `open`：夹爪分开，条件片背面朝外。
- `enforcing`：夹爪夹住目标，压力刻度亮起。
- `satisfied`：止动销完全落位，光线稳定。
- `violated`：中央止动销无法落位，保留一条琥珀缝。
- `released`：夹爪退回但保留边界刻痕。

**退出：** 先解除压力齿，再翻回条件片，最后夹爪沿原机械缝收回。

## 音效建议

- 夹爪定位：细密刻度声。
- 夹合：低音量 clamp click。

## HTML / CSS / GSAP 实现

数据单元、关键词组、中间结果、特征块、语义片段。

- **排除：** 长句、来源说明、风险提示

## 静态视觉描述

一枚由 2–4 个机械分段组成的短厚载荷块，顶部是低反射信息窗，侧面有阶段刻槽，底部有与母轨道吻合的导向脚。不同处理阶段通过分段重排、合并或锁定体现，不能只换颜色。

- **材质：** 深钛载荷外壳、烟灰玻璃信息窗、冷青导向脚、局部暖白锁线
- **相对尺寸：** 宽度为父锚点 7%–16%，高度为 6%–12%。

- **16:9：** 可同时展示 2–4 枚，但只允许一枚处于主动变形。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【数据名】` | 8 | 1 | 是 | — |
| `【数据值】` | 8 | 1 | 否 | — |

## 动态出现方式

载荷块从母模块输入槽或上一个功能单元内部短距离推出，导向脚先咬合轨道，再开始移动。

## 动态过程中每一步怎么变化

1. 导向脚下降并嵌入轨槽。
2. 载荷块沿 SVG 路径或 CSS 轨道匀速移动。
3. 进入处理区后，分段按语义顺序重排或压缩。
4. 到达结果端时，分段合并成完整块或沉入结果舱。

### 状态变化

- `raw`：分段之间有清晰缝隙。
- `processing`：仅当前分段重新排列。
- `merged`：分段缝隙闭合，形成单一结果芯。
- `consumed`：载荷块下降进入结果槽。
- `rejected`：导向脚被侧向分流到隔离槽。

**退出：** 沿原轨道进入下一结构或沉入母模块内部；禁止自由飞散。

## 音效建议

- 导向脚咬合：轻金属 tick。
- 分段合并：低音量磁吸声。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-data-payload` 内含 `.payload-segment[]`、`.info-window`、`.guide-foot`、`.phase-notch`。
- **CSS：** 分段使用相邻切角保持组合感；信息窗独立遮罩；导向脚必须与轨道视觉接触。
- **SVG：** 使用母模块已有 SVG 路径，通过 MotionPathPlugin 或路径采样移动。
- **GSAP：** `dock` 咬合导向脚，`process` 沿母轨道移动并重排分段，`resolve` 合并或沉入。
- **伪 3D：** 沿轨道只做轻微 `translateZ(4px)`；不得翻滚。
- **素材：** 无需图片素材。
- **低动态模式：** 以 3 个离散轨道位置切换，保留分段重排。

## 组合预算

- `visual_weight=2`，`motion_weight=2`，`text_weight=1`，`dominant=false`。
- 单个母模块最多 4 个实例；每增加一个实例，视觉权重增加 0.65。
- **适合搭配：** C01, C06, C08, C12
- **避免同用：** C17
- **可接转场：** TR01, TR04

## 禁止事项

- 不要用随机粒子代替数据。
- 不要脱离轨道漂浮。
- 不要让所有载荷同时重排。
- 不要在载荷上放两行以上文字。

## QA 失败判定

- 导向脚未接触母轨道，失败。
- 处理前后外形完全相同，仅换颜色，失败。
- 载荷块穿过文字或结构，失败。
- 多个载荷相互重叠，失败。

# C04｜关键词嵌片｜Keyword Inlay

**类别：** 文字强调
**集成模式：** `slot_enhancer`
**作用：** 在主标题、步骤、结论或错误句中突出一个真正关键的中文词，不增加新的信息层级。

- **锚点：** `title_mount`, `node_mount`, `result_mount`, `summary_mount`, `boundary_mount`
- **母时间线阶段：** `load`, `process`, `resolve`, `hold`

## 承载的信息类型

关键词、核心动词、错误词、结论词、概念词。

## 自动选择标签

- **正向标签：** 关键词强调、错误定位、记忆点、概念核心
- **触发词：** 关键是、核心、注意、错误在、记住、真正
- **排除：** 整句说明、来源名、日期、数值表

## 静态视觉描述

一枚极薄的梯形金属嵌片，被压入母模块文字板预留的浅槽中，表面与母板基本齐平，只在两端露出 1–2px 机械止动边。颜色可以是低饱和暖白或暗金，但面积必须很小。它不是背景标签，而是原句结构的一部分。

- **材质：** 钛金属或暗金合金、哑光刻字面、两端冷色止动边
- **相对尺寸：** 宽度为父锚点 8%–26%，高度为 3%–7%。

- **16:9：** 可嵌入标题或结果板，但总强调面积小于文字板 18%。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【关键词】` | 6 | 1 | 是 | — |

## 动态出现方式

母文字板先打开一条 2px 深的浅槽，嵌片由槽内或侧边短距离进入并压至齐平。

## 动态过程中每一步怎么变化

1. 浅槽边缘先露出一圈定位线。
2. 嵌片沿槽进入并被两端止动边夹住。
3. 文字由中央向两侧形成浅凹刻。
4. 确认时嵌片下沉 1px，与母板齐平。

### 状态变化

- `hidden`：只见浅槽。
- `focused`：嵌片略高于母板 2px。
- `confirmed`：嵌片下沉齐平，止动边锁住。
- `invalid`：嵌片停在半入槽状态。

**退出：** 确认后的嵌片优先与母板一起退出；不得单独飞走。

## 音效建议

- 入槽：很轻的金属贴合声。
- 下沉确认：短促 press tick。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-keyword-inlay` 内含 `.inlay-groove`、`.inlay-strip`、`.inlay-text`、`.end-stop[]`。
- **CSS：** 禁止圆角胶囊；用梯形 `clip-path` 和内嵌阴影；亮色面积严格受控。
- **SVG：** 无需 SVG。
- **GSAP：** `reveal` 打开浅槽并将嵌片移入；`resolve` 下沉 1px 并锁止。
- **伪 3D：** 最大 `translateZ(3px)`，不允许独立透视。
- **素材：** 无需图片素材。
- **低动态模式：** 浅槽与嵌片在两个 120ms 状态中切换。

## 组合预算

- `visual_weight=1`，`motion_weight=1`，`text_weight=1`，`dominant=false`。
- 单个母模块最多 2 个实例；每增加一个实例，视觉权重增加 0.5。
- **适合搭配：** C02, C07, C29, C30
- **避免同用：** C04
- **可接转场：** TR06, TR08

## 禁止事项

- 不要做成荧光笔高亮。
- 不要用圆角底色包住整词。
- 不要同时强调三个以上词。
- 不要让嵌片闪烁。

## QA 失败判定

- 强调词不是原句中的关键信息，失败。
- 嵌片遮住母板文字，失败。
- 颜色面积过大抢过主结论，失败。
- 使用普通下划线代替物理嵌片，失败。

# C06｜工具接口栓｜Tool Port Coupler

**类别：** 系统与连接
**集成模式：** `connector`
**作用：** 表示模型、Agent 或工作流调用了一个工具、API、插件或外部能力，并显示连接状态。

## 适合嵌入的大模块

- **优先：** M12 模型架构解剖台、M16 多源汇流总线、M19 反馈迭代轨道

- **母时间线阶段：** `load`, `process`, `resolve`

## 承载的信息类型

工具名、调用动作、接口状态、API、函数。

## 自动选择标签

- **正向标签：** 工具调用、API、函数、插件、外部能力
- **触发词：** 调用工具、API、插件、函数、搜索、执行、连接
- **排除：** 纯文件输入、最终总结、来源日期

## 静态视觉描述

一枚短六棱接口栓，前端有三根定位针，中段为刻有工具名的哑光套筒，尾端是一圈可转动的锁环。接口栓必须对准母模块的实体端口，插入后只露出锁环和文字窗。

- **材质：** 枪灰六棱合金、陶瓷定位针、烟灰文字窗、冷青接口环
- **相对尺寸：** 宽度为父锚点 9%–18%，高度为 7%–13%。
- **9:16：** 同屏最多 2 个工具接口；工具名必须一行。
- **16:9：** 可在架构背板上并列 2–3 个，但锁环方向一致。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【工具名】` | 8 | 1 | 是 | — |
| `【调用动作】` | 8 | 1 | 否 | — |

## 动态出现方式

定位针先伸入端口，接口栓前进 6–10px，锁环再顺时针转 20°–28°完成连接。

## 动态过程中每一步怎么变化

1. 定位针与端口孔位逐一对齐。
2. 接口栓沿端口轴线插入。
3. 锁环转至刻度缺口并停止。
4. 调用动作通过套筒上的窄窗显影。

### 状态变化

- `disconnected`：定位针未插入，锁环缺口错位。
- `connected`：锁环到位，接口线稳定。
- `calling`：套筒内部一枚短脉冲经过一次。
- `returned`：尾端结果销伸出 2px。
- `unavailable`：锁环停在半程，端口保护片保持关闭。

**退出：** 结果销收回，锁环反转到解锁刻度，接口栓沿原轴线退出。

## 音效建议

- 定位：三次极轻触点声。
- 锁环：短促 quarter-turn click。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-tool-coupler` 内含 `.locator-pin[]`、`.coupler-body`、`.tool-window`、`.lock-ring`、`.return-pin`。
- **CSS：** 使用六边切角与环形刻度；不要使用插头或链条图标。

# C11｜版本铆牌｜Version Rivet Plate

**类别：** 来源与时间
**集成模式：** `additive`
**作用：** 固定版本号、发布日期、模型代次或资料时间，强调“这是哪个版本”。

## 承载的信息类型

版本号、日期、代次、修订号、时间标记。

## 自动选择标签

- **触发词：** 版本、发布日期、更新、v1、v2、模型代次、修订
- **排除：** 长说明、结果结论、风险动作

## 静态视觉描述

一枚安装在母结构角落的 L 形薄金属铆牌，表面分成版本窗和日期窗，两端由真实铆钉固定。牌体略微压住母板边缘，表现为后装的可靠标识，而不是浮动角标。

- **16:9：** 可沿统一基线排列，但不得占用主标题区。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【版本】` | 8 | 1 | 是 | — |
| `【日期】` | 10 | 1 | 否 | — |

## 动态过程中每一步怎么变化

1. 牌体绕固定铰链翻到正面。
2. 版本窗先显示。
3. 日期窗随后打开。
4. 两枚铆钉按左后右顺序压入。

### 状态变化

- `current`：两枚铆钉完全压入。
- `superseded`：右侧铆钉抬起 1px，并出现替换刻痕。
- `archived`：牌体回落到较暗刻度，不闪烁。

**退出：** 随母板整体退出；版本被替换时，旧牌沿铰链翻回后新牌再装入。

## 音效建议

- 铆钉下压：两次短 tick。

## HTML / CSS / GSAP 实现

- **CSS：** L 形或梯形薄片，禁止普通右上角 badge。
- **SVG：** 可选短版本刻度。
- **GSAP：** `reveal` 翻面，`load` 打开文字窗，`resolve` 下压铆钉。

- **素材：** 无需图片素材。

- **适合搭配：** C05, C13, C17, C18
- **避免同用：** C27
- **可接转场：** TR05, TR06

## 禁止事项

- 不要做成普通日期角标。
- 不要给每个节点都贴版本。
- 不要滚动显示日期。
- 不要使用大面积亮色。

- 旧版本状态仍与当前版本同亮度，失败。

# C12｜校验码滚轮｜Checksum Drum

**类别：** 验证与状态
**集成模式：** `status`
**作用：** 显示短校验码、匹配状态或一致性检查结果，适合来源合并、工具调用和架构数据传递。

## 适合嵌入的大模块

- **优先：** M12 模型架构解剖台、M16 多源汇流总线
- **允许：** M03 证据鉴定托盘、M12 模型架构解剖台、M16 多源汇流总线、M17 可信度坐标仪
- **锚点：** `status_mount`, `source_mount`, `connector_mount`, `metric_mount`
- **母时间线阶段：** `process`, `resolve`

## 承载的信息类型

校验码、哈希短码、匹配状态、一致性。

## 自动选择标签

- **正向标签：** 校验、一致性、匹配、哈希
- **触发词：** 校验、匹配、一致、哈希、checksum、签名
- **排除：** 长编号、随机数字装饰、结果指标

## 静态视觉描述

一组 4–6 个横向机械滚轮，嵌在窄金属槽中，每个滚轮只显示一个字符或状态刻痕。滚轮右端有制动齿，最终值到位后必须机械刹停。它不是老虎机数字效果。

- **材质：** 黑色字符滚轮、枪灰槽体、钢质制动齿、冷青匹配刻线
- **相对尺寸：** 宽度为父锚点 10%–24%，高度为 5%–9%。
- **9:16：** 最多 6 位短码；若只显示状态，可使用 3 个符号槽。
- **16:9：** 可放在数据端口旁，不能横跨整个总线。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【校验码】` | 8 | 1 | 否 | — |
| `【校验状态】` | 6 | 1 | 是 | — |

## 动态出现方式

槽盖后退，滚轮按从左到右顺序转到确定字符；最后一枚制动齿落下后才显示状态文字。

## 动态过程中每一步怎么变化

1. 字符滚轮依次转动到目标值，禁止随机多圈。
2. 右端制动杆向下压。
3. 匹配刻线与母端口刻度对齐。
4. 状态窗打开。

### 状态变化

- `checking`：滚轮尚未完全到位。
- `match`：全部制动齿闭合。
- `mismatch`：一枚滚轮停在偏离刻度，并由机械挡片隔开。
- `expired`：槽盖半闭，状态窗显示过期。

**退出：** 先关闭状态窗，再释放制动齿，滚轮回到隐藏位。

## 音效建议

- 滚轮：细密、短促的字符 tick。
- 制动：清晰但低音量 click。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-checksum-drum` 内含 `.char-wheel[]`、`.brake-bar`、`.match-line`、`.state-window`。
- **CSS：** 每个字符轮独立遮罩；不要使用滚动数字库的无限循环。
- **SVG：** 匹配刻线可用短线 SVG。
- **GSAP：** 字符轮按确定最短路径转到目标字符，`resolve` 下压制动杆并打开状态窗。
- **伪 3D：** 滚轮可绕 X 轴小角度转动；槽体固定。
- **素材：** 无需图片素材。
- **低动态模式：** 字符直接切换，保留制动杆动作。

## 组合预算

- `visual_weight=2`，`motion_weight=2`，`text_weight=1`，`dominant=false`。
- 单个母模块最多 1 个实例；每增加一个实例，视觉权重增加 1.0。
- **适合搭配：** C05, C06, C13, C14
- **避免同用：** C27
- **可接转场：** TR05

## 禁止事项

- 不要做成老虎机滚动。
- 不要使用无意义随机码。
- 不要显示超过 8 个字符。
- 不要仅靠绿色表示匹配。

## QA 失败判定

- 滚轮转动多圈且无法对应目标值，失败。
- 校验结果在制动前出现，失败。
- 短码字体被压缩，失败。
- 不匹配没有结构性偏差，失败。

## 静态视觉描述

一枚细长的机械铭针，针尖固定在具体事实片或事件节点边缘，针头是一块微型来源铭牌；针身旁有一条受控短连带，可接回来源槽。它不是地图定位针，也不能扎在空白处。

## 文字槽位与硬上限

|---|---:|---:|---|---|
| `【来源】` | 10 | 1 | 是 | — |
| `【日期】` | 8 | 1 | 否 | — |

## 动态出现方式

3. 来源头绕小铰链翻正。

### 状态变化

- `attached`：针尖锁定，来源头清晰。
- `corroborated`：短连带另一端也锁定。
- `disputed`：针身旁出现一枚分歧缺口。
- `missing`：针尖悬空，来源头保持背面。

**退出：** 先收回短连带，再抬起针尖；若转场接 TR04，可将来源头压缩为数据令牌。

## HTML / CSS / GSAP 实现

- **CSS：** 针身必须细而清晰，来源头使用硬切角；不要使用地图 pin 轮廓。
- **SVG：** 短连带可使用 SVG 路径，必须沿母结构边缘。
- **GSAP：** `dock` 对准并下压针尖，`reveal` 翻正来源头，`process` 展开短连带。
- **伪 3D：** 针尖沿 Z 轴移动 2–6px；来源头翻转不超过 20°。
- **素材：** 无需图片素材。
- **低动态模式：** 针尖锁定与来源头翻正分两步。

## 组合预算

- `visual_weight=1`，`motion_weight=1`，`text_weight=1`，`dominant=false`。
- 单个母模块最多 4 个实例；每增加一个实例，视觉权重增加 0.55。
- **适合搭配：** C11, C14, C17, C16
- **避免同用：** C04
- **可接转场：** TR04, TR06

## 禁止事项

- 不要做成地图定位图标。
- 不要用长线跨越整个画面。
- 不要连接到模糊的“互联网”。
- 不要让针头随机摇摆。

## QA 失败判定

- 针尖没有绑定具体事实，失败。
- 连带穿过其他文字，失败。
- 来源名超过上限缩字，失败。
- 缺失来源仍显示已锁定，失败。

- **适合搭配：** C13, C15, C16, C17

- **可接转场：** TR01, TR04

- **避免同用：** C26
- **可接转场：** TR05

## 禁止事项

- 不要脱离刻度轨。

# C17｜证明碎片托｜Evidence Fragment Cradle

- **适合搭配：** C07, C11, C13, C14
- **避免同用：** C03
- **可接转场：** TR06, TR08

一枚可插入母模块测量槽的短刻度匣，内部有固定标尺、目标缺口和一枚机械游标。指标名位于上沿窄铭牌，数值与单位位于游标旁的低反射窗。它不是仪表盘卡片。

- **材质：** 深钛刻度匣、黑色标尺、钢质游标、冷青目标缺口
- **相对尺寸：** 宽度为父锚点 14%–30%，高度为 7%–14%。
- **9:16：** 最多 2 枚；数值和单位必须同一基线。
- **16:9：** 可横向或竖向插入，但同一页面刻度方向统一。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【指标】` | 8 | 1 | 是 | — |
| `【数值】` | 8 | 1 | 是 | — |
| `【单位】` | 4 | 1 | 否 | — |

## 动态出现方式

刻度匣先沿导向槽插入，刻度齿逐格升起；游标从基线移动到目标值，最后落入止动缺口。

## 动态过程中每一步怎么变化

1. 匣体插入测量槽。
2. 固定刻度逐格显露。
3. 目标缺口弹起。
4. 游标移动到数值并锁定。

### 状态变化

- `baseline`：游标停在基线。
- `current`：游标停在当前值。
- `target`：游标与目标缺口重合。
- `out_of_range`：游标被边界挡片阻止在范围外。

**退出：** 先释放游标止动，再收起刻度齿，匣体沿原槽回收。

## 音效建议

- 刻度齿：细密 tick。
- 游标锁定：短 click。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-metric-cartridge` 内含 `.metric-label`、`.fixed-scale`、`.scale-tooth[]`、`.cursor`、`.target-notch`、`.value-window`。
- **CSS：** 使用固定标尺和实体游标；禁止仪表盘卡片。
- **SVG：** 长刻度可用 SVG，但游标与目标缺口必须是有厚度的 DOM。
- **GSAP：** `dock` 插入匣体，`reveal` 升刻度，`process` 移动游标，`resolve` 锁入目标缺口。
- **伪 3D：** 匣体 `translateZ(4px)`，游标沿单轴移动。
- **素材：** 无需图片素材。
- **低动态模式：** 刻度出现、游标到位、锁定三段。

## 组合预算

- `visual_weight=2`，`motion_weight=2`，`text_weight=1`，`dominant=false`。
- 单个母模块最多 2 个实例；每增加一个实例，视觉权重增加 0.8。
- **适合搭配：** C01, C09, C16, C25, C26
- **避免同用：** C27
- **可接转场：** TR05

## 禁止事项

- 不要做成普通仪表盘。
- 不要滚动随机数字。
- 不要没有单位却显示精确值。
- 不要同时使用三种刻度方向。

## QA 失败判定

- 游标未对应数值位置，失败。
- 目标值在游标到位前显示完成，失败。
- 数值和单位错位，失败。
- 越界状态只靠红色，失败。

# C25｜差异游标｜Difference Caliper

**类别：** 测量与比较
**集成模式：** `measurement_connector`
**作用：** 在两个已有对象之间量出关键差值、偏移或变化量，强调“差多少”而不是简单箭头。

## 适合嵌入的大模块

- **优先：** M05 双轨差异舱、M15 决策配重引擎
- **允许：** M04 错误校准仪、M05 双轨差异舱、M11 参数影响风洞、M15 决策配重引擎、M17 可信度坐标仪
- **锚点：** `comparison_mount`, `metric_mount`, `connector_mount`, `boundary_mount`
- **母时间线阶段：** `process`, `resolve`

## 承载的信息类型

差值、变化量、偏移、A/B 差异。

## 自动选择标签

- **正向标签：** 差异、对比、变化量、偏移
- **触发词：** 相差、高出、低于、变化、提升、减少、差值
- **排除：** 没有两个测量对象、纯定性比较

## 静态视觉描述

一把小型精密卡尺，左右或上下两枚量爪分别夹住 A、B 的真实刻度点，中间是一枚窄差值窗。量爪沿刚性测量梁移动，差值窗只在两爪都接触后打开。

- **材质：** 枪灰测量梁、钢质量爪、黑色差值窗、冷青基准刻线
- **相对尺寸：** 宽度为父锚点 16%–36%，高度为 6%–14%。
- **9:16：** 只量一个关键维度；禁止跨越两行文本。
- **16:9：** 可横向跨 A/B 轨，但测量梁不得超过父模块 45%。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【维度】` | 6 | 1 | 否 | — |
| `【差值】` | 8 | 1 | 是 | — |

## 动态出现方式

测量梁先与 A/B 基线平行，两个量爪分别移动并接触对应刻度，最后中央差值窗打开。

## 动态过程中每一步怎么变化

1. 基准梁锁定方向。
2. A 量爪接触第一个对象。
3. B 量爪接触第二个对象。
4. 游标尺读取间距并打开差值窗。

### 状态变化

- `equal`：两爪间距归零，中央锁扣闭合。
- `a_higher`：游标偏向 A 侧并显示正差值。
- `b_higher`：游标偏向 B 侧。
- `unknown`：一枚量爪未接触，差值窗保持关闭。

**退出：** 先关闭差值窗，再释放两爪并缩回测量梁。

## 音效建议

- 量爪接触：两次轻 click。
- 差值读取：短游标声。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-difference-caliper` 内含 `.caliper-beam`、`.jaw-a`、`.jaw-b`、`.delta-cursor`、`.delta-window`。
- **CSS：** 梁体必须有实体厚度；禁止箭头或括号替代量爪。
- **SVG：** 可用基准线作为定位参考。
- **GSAP：** `dock` 锁定基准梁，`process` 移动两爪，`resolve` 打开差值窗。
- **伪 3D：** 量爪沿单轴移动，梁体固定。
- **素材：** 无需图片素材。
- **低动态模式：** 两爪直接接触目标，差值窗随后打开。

## 组合预算

- `visual_weight=3`，`motion_weight=2`，`text_weight=1`，`dominant=true`。
- 单个母模块最多 2 个实例；每增加一个实例，视觉权重增加 1.0。
- **适合搭配：** C24, C26, C29, C30
- **避免同用：** C09, C20
- **可接转场：** TR05

## 禁止事项

- 不要用箭头表示差值。
- 不要没有两个锚点就出现。
- 不要同时量三个维度。
- 不要让量爪穿过文字。

## QA 失败判定

- 任一量爪未接触对象，失败。
- 差值窗提前打开，失败。
- 差值与刻度距离不一致，失败。
- 量尺遮挡 A/B 标签，失败。

# C26｜决策配重块｜Decision Weight Block

**类别：** 测量与决策
**集成模式：** `measurement`
**作用：** 承载一个判断标准的权重和得分，并真正改变决策梁或比较轨的受力。

## 适合嵌入的大模块

- **优先：** M15 决策配重引擎
- **允许：** M05 双轨差异舱、M15 决策配重引擎、M17 可信度坐标仪
- **锚点：** `metric_mount`, `comparison_mount`, `evidence_mount`
- **母时间线阶段：** `load`, `process`, `resolve`

## 承载的信息类型

判断标准、权重、得分、优先级。

## 自动选择标签

- **正向标签：** 决策权重、评分标准、优先级
- **触发词：** 权重、得分、优先级、标准、更重要
- **排除：** 证据来源、单一结果指标

## 静态视觉描述

一枚带有标准刻面的高密度金属配重块，底部有双轨槽，侧面有权重缺口与得分齿。配重块沿母决策轨滑到指定刻度并锁住，使决策梁产生真实、克制的偏移。

- **材质：** 钨灰高密度金属、深钛双轨槽、暖白权重缺口、黑色得分齿
- **相对尺寸：** 宽度为父锚点 7%–14%，高度为 7%–14%。
- **9:16：** 最多 4 个标准，建议 3 个。
- **16:9：** 最多 5 个，所有配重块尺寸一致，权重由刻度位置表达。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【标准】` | 8 | 1 | 是 | — |
| `【权重】` | 4 | 1 | 是 | — |
| `【得分】` | 4 | 1 | 否 | — |

## 动态出现方式

配重轨向前展开，配重块从轨道起点滑到权重刻度；得分齿落入对应槽后，母决策梁才偏移。

## 动态过程中每一步怎么变化

1. 标准刻面翻正。
2. 配重块沿轨移动到权重位置。
3. 得分齿选择目标槽。
4. 双轨锁扣合，母梁响应。

### 状态变化

- `active`：参与决策，双轨锁闭合。
- `ignored`：移入旁轨，不影响母梁。
- `locked`：最终权重固定。
- `overweighted`：边界挡片阻止继续前进。

**退出：** 先解除双轨锁，再沿轨回收；不得从上方掉落或弹走。

## 音效建议

- 滑轨：轻金属游标声。
- 双轨锁：短促 clamp。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-decision-weight` 内含 `.weight-body`、`.criterion-face`、`.weight-notch`、`.score-tooth`、`.dual-lock`。
- **CSS：** 配重块尺寸保持一致，禁止用大小直接表示权重。
- **SVG：** 复用母决策轨刻度。
- **GSAP：** `load` 展开轨道，`process` 滑到权重位并选择得分齿，`resolve` 锁定并驱动母梁。
- **伪 3D：** 只沿轨道移动，最多 `translateZ(4px)`。
- **素材：** 无需图片素材。
- **低动态模式：** 直接到目标刻度，保留得分齿与母梁响应。

## 组合预算

- `visual_weight=2`，`motion_weight=2`，`text_weight=1`，`dominant=false`。
- 单个母模块最多 5 个实例；每增加一个实例，视觉权重增加 0.65。
- **适合搭配：** C24, C25, C30
- **避免同用：** C16
- **可接转场：** TR05

## 禁止事项

- 不要从上方掉落。
- 不要用不同大小表示权重。
- 不要没有标准名称。
- 不要让决策梁剧烈摇摆。

## QA 失败判定

- 配重锁定后母梁无变化，失败。
- 忽略项仍影响结果，失败。
- 权重和得分混淆，失败。
- 配重超过 5 个导致拥挤，失败。

## 自动选择标签

## 文字槽位与硬上限

1. 鼓架翻到阅读角度。
2. 指标刻面显影。
3. 数字鼓依次到达确定值。

**退出：** 先抬起制动片，再将鼓架折回结果板；若接 TR05，可保留最终刻度用于下一镜头。

## HTML / CSS / GSAP 实现

- **素材：** 无需图片素材。
- **低动态模式：** 数字直接切换，保留制动片。

## 组合预算

- `visual_weight=2`，`motion_weight=2`，`text_weight=1`，`dominant=false`。

# C28｜风险熔断片｜Risk Fuse Plate

**类别：** 风险与边界
**集成模式：** `risk`
**作用：** 把风险、禁止条件或安全阈值放在真实路径上；风险触发时物理阻断信息流。

## 适合嵌入的大模块

- **优先：** M14 风险守门闸
- **允许：** M06 操作路径芯轨、M11 参数影响风洞、M14 风险守门闸、M17 可信度坐标仪、M18 误区分离器
- **锚点：** `risk_mount`, `branch_mount`, `boundary_mount`, `payload_track`
- **母时间线阶段：** `process`, `resolve`

## 承载的信息类型

风险项、安全阈值、禁止条件、阻断动作。

## 自动选择标签

- **正向标签：** 风险提醒、熔断、安全阈值、停止条件
- **触发词：** 风险、停止、禁止、敏感、隐私、越界、阈值
- **排除：** 普通错误、来源冲突

## 静态视觉描述

一片跨接在母路径上的陶瓷金属熔断片，两端有夹座，中部是一条可收回的导电桥。安全时桥体连通；触发风险时桥体向内部缩回，路径被实体断开，并露出短风险铭牌。

- **材质：** 黑色陶瓷熔断片、深钛夹座、钢质导电桥、低饱和琥珀风险缝
- **相对尺寸：** 宽度为父锚点 12%–26%，高度为 6%–12%。
- **9:16：** 最多一枚主熔断片；必须跨在真实路径上。
- **16:9：** 可置于主路径或旁路入口，不能横跨多个无关通道。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【风险】` | 8 | 1 | 是 | — |
| `【安全动作】` | 10 | 1 | 否 | — |

## 动态出现方式

两端夹座先扣住路径，导电桥接通；检测到风险后，中央桥体沿自身槽收回并锁止。

## 动态过程中每一步怎么变化

1. 夹座咬住路径两端。
2. 导电桥伸出形成连通。
3. 风险条件到达时止动销释放。
4. 桥体缩回，风险铭牌翻出。

### 状态变化

- `safe`：导电桥连通，夹座稳定。
- `warning`：桥体仍连通，但止动销处于待释放。
- `tripped`：桥体完全缩回，路径断开。
- `replaced`：新桥体从夹座内部装入并重新接通。

**退出：** 安全恢复时先装入新桥体，再闭合夹座；普通退出随母路径收回。

## 音效建议

- 夹座：两次轻扣合。
- 熔断：短促机械 snap，避免爆炸声。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-risk-fuse` 内含 `.clamp-left`、`.clamp-right`、`.conductive-bridge`、`.trip-pin`、`.risk-plaque`。
- **CSS：** 使用陶瓷断口和实体桥体，禁止红色警报条。
- **SVG：** 可复用母路径，不使用闪电图标。

- **低动态模式：** 连通与断开两态切换，保留止动销。

## 组合预算

- **避免同用：** C15
- **可接转场：** TR02, TR08

- 不要爆炸或烧毁。
- 不要不跨路径就出现。
- 不要把普通提示都做成熔断。

## 承载的信息类型

适用范围、允许区间、概念边界、例外、上下限。

- **触发词：** 范围、边界、仅适用、不包括、上限、下限、例外

## 静态视觉描述

一对从母板或刻度边缘伸出的厚金属括箍，内侧有细刻度和止动齿。左右、上下或环向括箍必须真正停在被定义范围的两端，中间区域保持干净可读。

## 动态出现方式

两枚括箍从范围两端的母结构缝中伸出，沿刻度移动到目标边界，止动齿落下后才显示范围文字。

## 动态过程中每一步怎么变化

1. 起始括箍定位。
2. 结束括箍定位。
3. 中间边界线仅连接两括箍。
4. 止动齿闭合，范围铭牌显影。

### 状态变化

- `defined`：两端止动齿闭合。
- `narrowed`：两括箍向内移动后重新锁定。
- `expanded`：两括箍向外移动但不越安全区。
- `violated`：一枚越界销顶住括箍，无法锁定。

## 音效建议

- 止动齿：两次短 click。

## HTML / CSS / GSAP 实现

- **CSS：** 括箍必须有厚度与刻度；禁止纯文字括号。
- **SVG：** 中间边界线可用 SVG，但只连接两括箍。
- **GSAP：** `dock` 伸出括箍，`process` 沿刻度定位，`resolve` 落止动齿并显影文字。
- **伪 3D：** 括箍沿单轴或环向轨道移动，不漂浮。
- **素材：** 无需图片素材。
- **低动态模式：** 两括箍直接定位，止动齿随后闭合。

## 组合预算

- `visual_weight=2`，`motion_weight=2`，`text_weight=1`，`dominant=false`。
- 单个母模块最多 2 个实例；每增加一个实例，视觉权重增加 0.8。
- **适合搭配：** C02, C04, C24, C28, C30
- **避免同用：** C25
- **可接转场：** TR05, TR06

## 禁止事项

- 不要用普通括号字符。
- 不要包住整块母模块。
- 不要无上下限信息时使用。
- 不要让边界线穿过文字。

## QA 失败判定

- 括箍没有停在真实边界，失败。
- 违反状态仍能闭锁，失败。
- 范围文字与括箍无关联，失败。
- 两对括箍交叉造成视觉噪声，失败。

# C30｜结论压印条｜Conclusion Imprint Rail

**类别：** 总结与行动
**集成模式：** `slot_replacement`
**作用：** 把一句最终结论、记忆点或下一步行动压入母模块的总结槽，作为信息收束而不是额外页脚卡片。

## 适合嵌入的大模块

- **优先：** M01 数据铸造槽、M20 结论封印舱
- **允许：** M01 数据铸造槽、M02 流程脊柱、M03 证据鉴定托盘、M04 错误校准仪、M05 双轨差异舱、M06 操作路径芯轨、M07 概念分解棱镜、M08 因果传动架、M09 知识核心层仓、M10 时间刻度轨仓、M11 参数影响风洞、M12 模型架构解剖台、M13 结果显影镜头、M14 风险守门闸、M15 决策配重引擎、M16 多源汇流总线、M17 可信度坐标仪、M18 误区分离器、M19 反馈迭代轨道、M20 结论封印舱
- **锚点：** `summary_mount`, `result_mount`, `interaction_mount`
- **母时间线阶段：** `resolve`, `hold`

## 承载的信息类型

最终结论、记忆点、核心原则、下一步行动。

## 自动选择标签

- **正向标签：** 结论、记住一句、核心原则、下一步
- **触发词：** 结论、记住、所以、核心是、下一步、最终
- **排除：** 长段总结、两个同级结论、来源列表

## 静态视觉描述

一条窄而厚的金属压印轨，从母模块原有的总结槽或记忆铭牌内部展开，两端各有一枚止动锁，中间是低反射长文字面。它是母模块总结槽的实现皮肤，不额外复制同一句，也不能像普通底部横条。

- **材质：** 深钛承重轨、哑光压印面、钢质双端锁、低亮暖白重点刻线
- **相对尺寸：** 宽度为父锚点 32%–72%，高度为 5%–10%。
- **9:16：** 只允许一条；距字幕安全区至少 24px。
- **16:9：** 可更宽，但不得占据画面整宽；人物在一侧时保持在母模块内部。

## 文字槽位与硬上限

| 槽位 | 最多字数 | 最多行数 | 必填 | 备注 |
|---|---:|---:|---|---|
| `【结论】` | 18 | 1 | 是 | — |
| `【下一步】` | 10 | 1 | 否 | — |

## 动态出现方式

总结槽盖板先向内收起，压印轨沿母结构轴线展开；两端锁定后，机械压印针从中央向两侧完成文字。

## 动态过程中每一步怎么变化

1. 槽盖收起，露出轨道导向槽。
2. 压印轨展开到目标长度。
3. 双端止动锁按左右顺序闭合。
4. 压印针从中央向两端形成文字凹刻。
5. 如有下一步，右端行动片最后翻出。

### 状态变化

- `draft`：轨道展开但端锁未闭合。
- `locked`：双端锁闭合，结论清晰。
- `actionable`：右端行动片翻出。
- `superseded`：压印面翻回，准备替换新结论。

**退出：** 先收行动片，再解除双端锁，压印轨沿原槽回收；若接 TR06，可将整条铭牌翻面成为下一镜头标题。

## 音效建议

- 轨道展开：低音量机械滑轨声。
- 压印：克制的机械刻字声。
- 端锁：两次短 click。

## HTML / CSS / GSAP 实现

- **DOM：** `.hf-micro.mc-conclusion-rail` 内含 `.rail-body`、`.end-lock[2]`、`.imprint-mask`、`.action-tab`。
- **CSS：** 长条必须有承重厚度、切角和内嵌文字面；禁止普通页脚卡片。
- **SVG：** 压印针路径可用短 SVG 线，但不得扫过文字。
- **GSAP：** `reveal` 展开轨道，`resolve` 闭合端锁并执行中央向两侧的文字遮罩，`hold` 翻出行动片。
- **伪 3D：** 轨道沿自身轴线展开，最多 `translateZ(6px)`。
- **素材：** 无需图片素材。
- **低动态模式：** 展开、锁定、显影三段切换。

## 组合预算

- `visual_weight=2`，`motion_weight=2`，`text_weight=2`，`dominant=false`。
- 单个母模块最多 1 个实例；每增加一个实例，视觉权重增加 1.0。
- **适合搭配：** C04, C07, C27, C29
- **避免同用：** C17
- **可接转场：** TR06, TR08

## 禁止事项

- 不要做成普通底部信息条。
- 不要重复母模块已有同一句。
- 不要放两条并列结论。
- 不要让 CTA 比结论更亮。

## QA 失败判定

- 压印条脱离母总结槽，失败。
- 结论超过 18 字后缩字，失败。
- 双端锁未闭合就显示最终状态，失败。
- 下一步行动抢过核心结论，失败。

## 5. 自动选型伪代码

```ts
const parent = selectParentModule(script); // M01-M20
const microNeeds = extractMicroNeeds(script, [
  "parameter", "file", "tool", "source", "evidence", "status",
  "metric", "condition", "risk", "interaction", "branch", "summary"
]);

const candidates = components
  .filter(c => c.compatibility.allowed_module_ids.includes(parent.module_id))
  .filter(c => hasAnchorOverlap(parent.anchor_map, c.compatibility.anchor_types))
  .map(c => ({ c, score: scoreComponent(c, microNeeds, parent) }))
  .filter(x => x.score >= 8)
  .sort((a, b) => b.score - a.score);

const selected = fitBudget(candidates, {
  maxTypes: aspect === "9:16" ? 4 : 5,
  maxVisibleInstances: 9,
  maxTextComponents: 3,
  maxDominant: 1,
  preventDuplicateSemantics: true
});

mountIntoParentAnchors(parent, selected);
attachToParentTimeline(parent.timeline, selected);
runReadyGate(parent, selected);
```
