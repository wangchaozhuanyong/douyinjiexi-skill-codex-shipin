# AI 解码封面设计描述库

本文件是 AI 知识类视频第一帧/发布封面的可复用设计描述库。当前阶段只固化封面场景、文字排版、系列标志、编号系统和合规清单，不生成图片。

## 固定成图优先规则

后续 AI 视频默认不再按本文件每次重新生成封面图。已通过本地检查和 Qingdou 检查的 10 张固定安全封面成图保存在 `assets/ai_cover_templates_fixed/`，机器可读轮换清单为 `references/fixed_ai_cover_template_rotation.json`，执行说明为 `references/fixed_ai_cover_template_rotation.md`。

生产时必须先按视频尺寸选池，再在池内顺序轮换：

- 16:9 / 1920x1080：H01 -> H02 -> H03 -> H04 -> H05 -> H01。
- 9:16 / 1080x1920：V01 -> V02 -> V03 -> V04 -> V05 -> V01。

选中的成图必须同时作为 `internal/first_frame_cover.png` 和 `internal/cover.png`。除非用户明确要求并重新通过本地合规与 Qingdou 检查，否则不要给固定封面额外叠加当期动态文字。

## 总原则

- 系列名称：`AI解码`。
- 封面第一帧使用真实电影级 AI 场景，不用卡通机器人，不用普通 PPT 卡片。
- 封面成图必须包含可控的文字设计、系列标志设计和编号设计；这些元素由后期图层渲染，不交给图片模型随机生成伪字。
- 场景层不生成乱码文字、随机数字、英文字母、品牌标志、二维码或伪界面；最终封面图层可以加入经过合规检查的中文主标题、系列标志、中文编号和分类标签。
- 主标题按当期视频动态填写，场景模板本身保持通用，适合反复用于不同 AI 视频。
- 每套模板保留统一六边形系列标志和中文编号系统；公开可见编号用 `壹` 到 `拾`，不使用阿拉伯数字。
- 背景可以满版、信息丰富，但标题区域必须做局部压暗、雾化或柔光承托，保证手机端可读。
- 主标题两行以内，单行尽量不超过九个汉字；副标题短句化；标签只使用真实内容分类。

## 安全文字系统

公开可见的系列、标志、编号和分类文字：

- 系列：`AI解码`
- 系列标志：六边形发光徽章，内部排版 `AI解码`
- 竖版分类：`AI快讯`、`工具体验`、`工作流`、`模型对比`、`趋势解读`
- 横版分类：`产业地图`、`算力拆解`、`智能体协同`、`应用案例`、`战略中枢`
- 编号：`壹`、`贰`、`叁`、`肆`、`伍`、`陆`、`柒`、`捌`、`玖`、`拾`

禁止写进封面的表达：

- 绝对承诺、恐吓、诱导互动、未经验证的效率数字。
- 暗示官方合作、内部来源、保收益或保效果。
- 当前学习库中的高风险字词已在公开文字清单中避开；维护时以 `references/forbidden_terms_learning_bank.jsonl` 为准。
