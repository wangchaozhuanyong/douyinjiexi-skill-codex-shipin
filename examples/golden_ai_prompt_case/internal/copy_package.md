# Copy Package

## First 5 Seconds

别再让 ChatGPT 帮你写空话文案。创作者先看这个前后对比。左边只写一句“帮我写一条视频文案”。右边补上对象、场景、格式和禁区。结果马上不同。

## Retention Beats

第1拍：错误纠正，指出泛泛提问会产出空话。
第2拍：真实界面，展示提示词截图和输出结果。
第3拍：证明墙，放三张截图组成对比证据。
第4拍：结果揭示，圈出更具体的标题和分镜。
第5拍：模板保存，给出可直接套的公式。

## 口播正文

先写目标用户，比如创作者、运营或老板。
再写使用场景，比如投流前测试、老板汇报或发布前自检。
再写输出格式，比如3个标题、5句口播和1个分镜表。
最后写禁区，比如不要编造案例，不要承诺涨粉，不要写空泛形容词。
这样模型知道边界。
这样观众也能直接复用。
每一步都配真实截图。
每一步都能检查。

## 前后对比计划

左边是错误做法。右边是正确做法。改前只有一句话。改后有对象、场景、格式、禁区和证据素材。

## 术语解释

Prompt 也就是提示词。简单说，就是你交给 AI 的任务说明。

## proof_visual_plan

证据画面使用真实截图、录屏、输出文件和对比结果。所有演示素材标注为演示，不伪装官方后台。

## 保存价值

收藏这条模板：对象 + 场景 + 输出格式 + 禁区 + 证据素材。

## Claim Ledger

只说演示结果，不承诺涨粉，不声称收益，不伪造用户评价。
