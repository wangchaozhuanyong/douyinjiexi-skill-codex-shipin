# AI Hook Pattern Bank

Use this before full script writing. The goal is not louder copy. The goal is a first 3 seconds line that names the tool, names the pain, and promises a visible result.

## Strong Shapes

- `别再让【工具】只回答问题了，先让它锁住【可见结果】。`
- `同一个需求，别人少返工，不是更会问，是先做了【关键动作】。`
- `今天不讲概念，只看【工具】怎么把【任务】跑成一个可验收结果。`
- `如果你用【工具】总是跑偏，先检查这三个输入。`
- `这不是教程清单，是一套能直接复用的【工作流】。`
- `【工具】最新变化，普通用户真正该改的是这一步。`
- `先别急着生成，让【工具】先读规则、证据和验收标准。`
- `你缺的不是提示词，而是让 AI 记住边界的办法。`
- `30 秒看懂：这个功能到底能省掉哪一步。`
- `我只保留一个判断标准：有没有可验证输出。`

## Reject

- pure hype: `神级`, `逆天`, `全网第一`, `秒杀`
- empty setup: `今天给大家分享一个非常有用的方法`
- generic promise: `提升效率`, `高级技巧`, `干货满满`
- no visible task
- no named tool/source
- no proof hint
